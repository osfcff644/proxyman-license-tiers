1 席和 2 席的差价，换来的是一台桌面设备加两个移动席位。判断标准很简单：你只有一台电脑，平时也不在手机上抓包，这钱就花不出去。官方的写法是「一个授权覆盖所有桌面平台」，意思是换操作系统不用重买，但席位仍然按设备数算，一台 Mac 加一台 Windows 就是两台。

## 买之前该知道的几个限制

**更新只有一年。** 这是这款产品最容易被忽略的一条。买断给的是永久使用权，不是永久升级权。你要的是长期跟着版本走，就得接受每隔一段时间为更新再付一次钱，而现在的定价页没告诉你那时候要付多少。

**席位是硬约束。** 1 席就是 1 台设备，两台机器轮着用不合规。授权可转让这一条是给出让整套授权用的，走的是转让流程，不是让你在同事之间换着激活。

**团队版有几个功能还没上线。** 单点登录和调试规则同步目前标着「即将上线」，官网没给时间。如果这两项是你选团队版的理由，先等等。

**授权怎么交付，得问清楚。** 数码荔枝是国内代理，付款之后是给授权码还是绑定账号、能不能跨区激活，商品页上的说明我没能核实到明确说法。下单前问一句客服，比事后扯皮省事。

**退款条款我没查到明确说明。** 稳妥的做法是按「买了就不退」来做决策，先把版本选对，再付款。
